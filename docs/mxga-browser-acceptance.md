# MXGA 浏览器运行时与发布验收

这份文档把三类证据分开记录，避免把纯逻辑测试或合成页面烟测误当成真实 X / Tampermonkey 验收：

1. Node 纯逻辑与构建门禁；
2. 真实浏览器内核中的合成 X DOM 运行时烟测；
3. 官方 Tampermonkey 从 GitHub Raw 安装后，在真实 `x.com` 页面上的发布验收。

## 2026-07-31 Chromium 运行时烟测

测试对象：

- 分享图资源管理：MXGA `0.2.2`，commit `5b209a0a58296ac46d29cd1c8e9ecca910840bf7`
- 增量扫描与重复注入：MXGA `0.2.3`，commit `62aac1d3356acc01578081e3ccde2d14e1863e0d`
- 两次测试均使用与对应 GitHub Raw SHA-256 一致的生成脚本
- headed Google Chrome，由 Playwright CLI 驱动
- 合成的公开推文 DOM；不使用 X 登录态、Cookie 或私人时间线

已观察结果：

- 连续触发分享按钮后，菜单中仍只有一个“生成分享图”入口。
- 文字推文能生成预览，弹窗中的复制与下载按钮进入可用状态。
- 使用宽高比 `20:1` 的合成长图时，实际 Canvas 为 `490 × 8192`，共 `4,014,080` 像素，未超过 800 万像素和 8192 最大边预算。
- 对图片请求增加 2.5 秒延迟后，在生成过程中关闭弹窗，观测到进行中的 fetch 被 abort；关闭后弹窗数量为 0，菜单入口数量仍为 1。
- 在 1000 条合成推文上连续触发 10 次局部 DOM 变化：优化前发生 10 次全页扫描并处理 10,000 条内容；增量扫描后不发生全页扫描，只处理 10 条受影响内容。新插入一条完整推文时只处理该 1 条。
- 同一页面连续注入两次生成脚本，第二次注入后 interval 与 MutationObserver 数量均未增加，MXGA UI root 仍只有一个。

这个烟测证明当前生成文件能在真实 Chromium 的 DOM、Canvas、Blob、Shadow DOM 和 AbortController 运行时中完成关键流程。它不证明 Tampermonkey 的 Raw 安装、真实 X DOM 兼容性或 iOS 内存稳定性。

## 2026-08-28 Chromium 快捷屏蔽烟测

测试对象为 MXGA `0.4.0` 候选生成脚本、headed Chromium 和三条合成 X 推文 DOM，不使用 X 登录态、Cookie 或私人时间线。

已观察结果：

- 三条推文的作者头像链接都只绑定一个 MXGA 快捷操作入口。
- 在第一条正文中划选 `Great insight` 后出现“屏蔽所选文字”工具条；点击后关键词写入 GM 设置，两条命中推文同时隐藏，未命中推文保留。
- hover 未命中公共名单的 `@hovertarget` 头像后出现账号操作浮窗；点击“本地屏蔽该用户”后，该账号写入本地隐藏记录并立即从页面消失。
- 账号记录标记为“手动屏蔽 · 头像操作”，仍可沿用设置面板和 5 秒撤销入口恢复。

这个烟测证明候选生成脚本能在真实 Chromium 内核中完成 selection、Shadow DOM 工具条、头像 hover 事件、GM 持久化和即时隐藏链路。它不替代官方 Tampermonkey Raw 安装、真实 `x.com` DOM 或 iOS 触控验收。

## 2026-08-28 Chromium 紧凑操作与同步烟测

测试对象为 MXGA `0.5.0` 候选生成脚本、headed Chromium、一条合成 X 推文 DOM 和模拟 GM 同步响应，不使用 X 登录态、Cookie 或私人时间线。

已观察结果：

- hover 作者头像时，只出现位于头像右上角的 `26 × 26 px` 屏蔽图标；点击后推文立即隐藏并出现 5 秒撤销提示。
- 划选 `Robot phrase` 后，只出现 `44 × 28 px` 的“屏蔽”按钮，tooltip 保留完整短语；点击后关键词写入 GM 设置并立即隐藏推文。
- 面板能保存同步密钥并完成一次模拟 `GET → POST`；本地关键词、同步 revision 和已配置状态均写入 GM 存储。
- 独立线上 Worker 的 `/health` 与公开空快照读取成功；使用仅存于 Cloudflare Secret 和本机钥匙串的写入密钥后，空文档 revision 从 `0` 前进到 `1`。

这个烟测证明紧凑 UI、即时隐藏、GM 持久化和同步请求链路能在真实 Chromium 内核运行。它不替代真实 `x.com` hover card、两台真实设备之间的同步或 iOS 触控验收。
