# Reading Notes Sync Worker

Cloudflare Worker + D1 backend for `ai-agent-book-reading-notes.user.js`.
The service stores only encrypted annotation payloads. Device credentials and
the library encryption key are generated by the userscript and must never be
committed to this repository.

## Create and deploy

```bash
cd services/reading-notes-sync
npx wrangler d1 create reading-notes-sync
```

Copy the returned database ID into `wrangler.jsonc`, then configure the
one-time bootstrap secret:

```bash
npx wrangler secret put BOOTSTRAP_TOKEN
npx wrangler d1 migrations apply reading-notes-sync --remote
npx wrangler deploy
```

After the first device initializes the only library, bootstrap requests are
rejected even if the secret is retained. Rotate or delete the secret after
initialization:

```bash
npx wrangler secret delete BOOTSTRAP_TOKEN
```

For local development:

```bash
npx wrangler d1 migrations apply reading-notes-sync --local
npx wrangler dev
```

The default local endpoint is `http://localhost:8787`.

## Trust model

- A one-time Worker secret authorizes the first device.
- Every device receives its own random credential; D1 stores only its SHA-256
  hash.
- A trusted device creates a five-minute invitation and approves the claimed
  device.
- The trusted device encrypts the library key to the new device's ephemeral
  P-256 ECDH key. The Worker only relays the encrypted envelope.
- Annotation payloads are encrypted by AES-GCM in the userscript.
- Revocation prevents future sync, but cannot erase notes already downloaded
  to an offline device.
